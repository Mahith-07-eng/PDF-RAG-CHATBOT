#  PDF RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that allows users to upload PDF documents and ask questions in natural language. The system retrieves relevant content from the uploaded PDFs using semantic search and generates grounded answers using Google's Gemini API.

##  Features

* Upload and process multiple PDF documents
* Automatic text extraction using PyMuPDF
* Recursive text chunking for efficient retrieval
* Semantic search using vector embeddings
* ChromaDB vector database for persistent storage
* Google Gemini-powered answer generation
* Source-aware responses with file names and page numbers
* Streamlit-based interactive web interface
* Retrieval-Augmented Generation (RAG) pipeline

##  How It Works

### Step 1: Upload PDFs

Users upload one or more PDF documents through the Streamlit interface.

### Step 2: Document Processing

The system extracts text from PDFs using PyMuPDF and splits it into overlapping chunks.

### Step 3: Vector Database Creation

Each chunk is converted into embeddings using the all-MiniLM-L6-v2 model and stored in ChromaDB.

### Step 4: Retrieval

When a user asks a question, the system performs similarity search and retrieves the most relevant chunks.

### Step 5: Answer Generation

The retrieved context is sent to Gemini API, which generates an answer strictly grounded in the document content.

### Step 6: Source Attribution

Responses include the source PDF file name and page number for traceability.
